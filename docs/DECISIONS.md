# Architectural Decisions Record (ADR)

This document formalizes the architectural decisions made for the `microservice-cicd-kubernetes` project, in accordance with the project completion plan.

| Decision ID | Topic | Decision | Justification | Date |
|---|---|---|---|---|
| **D1** | **Container Registry for AWS** | Maintain GHCR for local/initial CI; provision and transition to **Amazon ECR** with immutable tags for AWS EKS deployment. | ECR natively authenticates with EKS nodes and IAM roles (no static `imagePullSecrets` or public package exposure). Demonstrates OIDC and cloud-native IAM integration. | 2026-11-05 |
| **D2** | **Kubernetes Packaging** | Use **Kustomize** with `base` and environment overlays (`minikube`, `eks`). Skip Helm for current scope. | Kustomize is natively built into `kubectl`, avoids templating engine overhead, cleanly manages image tag replacement per environment, and avoids rewriting manifests. | 2026-11-05 |
| **D3** | **Continuous Deployment Strategy** | Direct deploy from GitHub Actions via **OIDC Federation** to AWS IAM roles and EKS Access Entries with automatic rollback on probe failure. | Eliminates long-lived AWS credentials in GitHub Secrets; scopes permissions strictly. Argo CD documented as future GitOps enhancement. | 2026-11-05 |
| **D4** | **Terraform Execution Model** | Terraform planning (`fmt`, `validate`, `plan`) automated in CI; `terraform apply` executed **locally by developer** with reviewed plans. | Prevents granting broad cloud-modifying write permissions to CI runners, minimizing blast radius and unexpected cloud spend. | 2026-11-05 |
| **D5** | **Worker Node Subnet Topology** | **Demo Mode:** Public subnets across 2 Availability Zones, restrictive Security Groups, no NAT Gateway. Variable toggle `enable_nat = false` with production private subnet documentation. | NAT Gateways incur mandatory continuous hourly charges (~$0.045/hr) plus data processing costs. Public subnets with strictly locked security groups provide zero-cost idle networking. | 2026-11-05 |
| **D6** | **Ingress Strategy on EKS** | Support **AWS Load Balancer Controller (ALB)** for public demo ingress, with `kubectl port-forward` as the zero-cost testing baseline. | `ingress-nginx` retirement roadmap; AWS ALB natively creates Application Load Balancers with AWS ACM and WAF integration. Created only during demo window to control hourly billing. | 2026-11-05 |
| **D7** | **AWS Region** | Standardized on **`ap-south-1` (Mumbai)**. | Minimizes round-trip network latency from India (Kerala), offers standard EKS and EC2 instance availability, and ensures consistent single-region cost tracking. | 2026-11-05 |
| **D8** | **Terraform Remote State & Locking** | Amazon S3 backend with **Native S3 Locking (`use_lockfile = true`)** for Terraform >= 1.10. DynamoDB table omitted. | Terraform v1.10+ supports native S3 object locking without requiring a separate DynamoDB table, simplifying state architecture and eliminating table provisioning. | 2026-11-05 |
